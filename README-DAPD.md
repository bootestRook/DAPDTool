# DAPD 任务工具

独立 Windows 桌面应用。支持 Windows 10/11 x64；无需安装 Python、飞书或 Codex，不调用 AI。需要联网访问 DAPD。

## 首次使用

1. 运行 `DAPDTool.Desktop-win-Setup.exe`，安装完成后从桌面快捷方式打开。更新功能由首次安装包一并安装；无需 Python、GitHub 账号或管理员权限。
2. 点击“连接设置”，粘贴 DAPD 个人设置 → 安全设置中生成的 API Key，点击“验证并保存”。
3. 选择项目、任务组。如果需要子任务，点击“选择父任务”，按标题关键词搜索，或粘贴任务链接。

也可以点击“粘贴任务组链接”，直接粘贴 DAPD 复制出来的整段文字，例如：
`示例版本（测试）（ https://dapd.dodjoy.com/groups/11111111-2222-4333-8444-555555555555?only=true ）`。
程序按链接中的 ID 定位项目与任务组，不依赖名称匹配。这里的文字仅为使用说明示例，不会预设到程序中。
父任务同样支持 `DAPD任务：任务标题（ https://dapd.dodjoy.com/task/任务ID ）` 这种完整复制文本。
“粘贴项目链接”支持 `DAPD项目：项目名（ https://dapd.dodjoy.com/groups/?projectId=项目ID ）`。

程序包不包含任何密钥、预设项目、任务或默认模板。

## 创建空任务

在“创建任务”中选择“空任务”，输入标题，点击“预览任务”。核对归属后点击创建。
父任务留空时建在任务组顶层；选择父任务后建为其子任务。
负责人、描述和日期留空，状态和优先级使用 DAPD 默认值。

## 自建模板与批量创建

1. 打开“我的模板” → “新建模板”，输入模板名。
2. 选中主任务，点击“添加子任务”。可以添加同级、增加多层子任务、调整顺序和层级；双击子任务修改标题。
3. 选中主任务或任意子任务，在右侧填写固定描述、插入图片、添加附件，再保存模板。主任务标题由每次创建时输入，所有节点的固定内容都会分别复用。
4. 回到“创建任务”，选择“按模板批量创建”，选择模板，每行输入一个主任务标题。
5. 预览完整任务树和总数，确认后创建。重复的主任务标题会要求先修改。

一个有 4 个子任务节点的模板，输入 3 个主任务标题，会创建 3 × 5 = 15 个任务。
每次最多 5000 个任务。模板变化不会改动已保存的批次记录。

## 固定描述、图片和附件

- 每个节点（包括主任务）分别保存文字、图片和附件。图片插入当前光标位置，可用键盘删除；粘贴文字按纯文本处理。
- 选择文件后先保存到本地模板资料库，提交创建时才上传到 DAPD。原文件移动或删除不影响已保存的副本。
- 支持 PNG、JPEG、WebP、BMP、TIFF、TGA 和静态 GIF。图片会生成去除 EXIF/GPS 等元数据的 PNG 副本，最长边限制到 4096 像素；不修改原图。不处理动态或多页图片。
- 附件还支持 PDF、Word、Excel、CSV、TXT 和常见音视频格式。单文件最大 50 MB；单个任务最多 100 个附件。SVG、压缩包等未列出的文件暂不支持。
- 描述图片会写入任务描述，附件会上传到该任务的“附件”区域，两者分别处理。
- 上传文件名带短批次标识，便于中断后准确核对。文件上传和任务创建分别保存进度，已确认成功的操作不会重复提交。
- 提交前的预览可选中每个节点查看其描述与附件。

## 进度和异常处理

- 点击“停止创建”会等待当前请求结束，再停止后续提交；已创建的任务保留。
- 在“创建记录”选择未完成的批次，点击“继续此批次”；已经成功的任务不会再次提交。
- 请求超时或程序在提交时中断，会显示“结果待核对”。先去 DAPD 确认；如果已经创建，选中该记录并点击“关联已创建任务”，粘贴任务链接。程序会核对标题及归属。
- 只有在 DAPD 中确认没有创建成功后，才能点击“确认未创建”，随后继续批次。否则可能生成重复任务。
- “已提交，待回读”表示已取得任务 ID，但尚未核对完成。继续时只回读该任务，不会重复创建。
- “上传结果待核对”时，继续批次会先查询已上传文件。若无法确认，会保持暂停；只有在 DAPD 确认相应文件不存在后，才能点击“确认文件未上传”。
- 可以打开所选任务，或导出带任务链接的 CSV 记录。
- 再次从“创建任务”发起提交是一个新批次，可以创建同名任务；续建请使用原来的创建记录。

## 数据与分发

密钥、模板和记录保存于 `%LOCALAPPDATA%\DAPDTaskTool`，与 EXE 分开。替换新版 EXE不会清除数据。
API Key 使用 Windows 当前用户的 DPAPI 加密。不要把本机数据目录作为分发包；其他人应自行填写 API Key。
需要备份模板和记录时，先关闭程序，再一起备份目录中的 `tasks.sqlite3` 和 `assets` 文件夹。
应用同一时间只允许一个实例运行。

程序安装到 `%LOCALAPPDATA%\DAPDTool.Desktop`，数据仍保存于 `%LOCALAPPDATA%\DAPDTaskTool`。从旧版升级时，先关闭旧程序，再运行首次安装包；新程序会使用同一份个人数据。

## 软件内更新

“更新与共享”读取公开仓库 `bootestRook/DAPDTool` 的 `updates.json` 更新索引，再从 GitHub Releases 下载文件。版本检查不调用 GitHub REST API，不消耗匿名 API 配额。软件启动时每天自动检查一次，也可以手动“检查更新”。

- 程序更新：查看说明，点击“下载程序更新”。下载并校验完成后，点击“重启并安装更新”；当前网络操作结束前不能重启升级。
- 共享内容：点击“同步共享内容”，下载模板、描述、图片和附件。完整校验后一次切换共享库，无需重启。
- 共享模板显示“共享”来源，可直接选择创建任务；点击“复制为个人模板”后可以编辑。同步不覆盖个人模板，也不修改已创建的 DAPD 任务。
- 网络失败或校验失败时保留当前版本；重新点击检查或下载即可重试。已下载的程序更新会保留到下次启动，仍由用户确认安装。
- 程序版本和内容版本分别递增。新内容需要更高程序版本时，会提示先升级程序。

## 发布者：更新共享模板和素材

1. 在“我的模板”编辑需要发布的个人模板，包括每个节点的描述、图片和附件。
2. 点击“导出共享内容包”，勾选要发布的模板，填写内容版本（例如 `1.0.0`）和说明，选择输出目录。
3. 在本项目目录使用 `.\.venv-desktop\Scripts\python.exe publish_release.py content "内容包的完整路径"` 上传。发布工具使用发布者本机 Git 凭据或环境变量 `GH_TOKEN`；客户端不保存发布凭据。
4. 也可在 GitHub Releases 手动新建标签 `content-v1.0.0`，上传导出的 `dapd-content-1.0.0.zip`，填写说明并正式发布（不要标为草稿或预发布，也不要标为 Latest）。随后运行 `publish_release.py index content-v1.0.0`，将该版本写入软件读取的更新索引；只上传 ZIP 不会通知客户端。
5. 同事打开软件检查更新后，即可同步。

每次发布使用新版本号，不覆盖已有发布。包内只有勾选的模板及其引用素材，不包含密钥、创建记录或未勾选模板。公开仓库中的包可被任何人下载。

## 发布者：程序新版

修改代码后，递增 `dapd_tool/__init__.py` 的 VERSION，更新 RELEASE-NOTES.md，运行测试和构建脚本，再运行 `publish_release.py app`。
脚本先创建发布草稿、上传并核对所有文件，再转为正式发布并更新仓库根目录的 `updates.json`。仅上传安装 EXE 不足以启用更新，必须同时上传构建生成的 `releases.win.json` 和 `*-full.nupkg`。
若版本发布成功但索引更新失败，运行 `publish_release.py index v版本号` 重试。发布后运行 `git pull --ff-only`，取回脚本写入仓库的索引提交。GitHub 的文件缓存可能需要数分钟刷新，稍后手动检查即可。

此构建没有数字签名。若 Windows 显示未知发布者，请核对文件来源和附带的 SHA256 校验值后再决定是否运行。

## 开发与构建

```powershell
python -m venv .venv-desktop
.\.venv-desktop\Scripts\python.exe -m pip install -r requirements-desktop.txt
dotnet tool install vpk --version 1.2.161 --tool-path .tools
.\.venv-desktop\Scripts\python.exe build_desktop.py
```

仅打包 `dapd_desktop.py`、`dapd_tool` 和已验证的 `dapd_api.py`，不打包聊天机器人、AI 模型包或任何运行数据。
构建生成包含运行库的程序目录，并通过 Velopack 生成首次安装 EXE、更新包和便携 ZIP。发布文件在 `release/Releases`，完整交付 ZIP 另含说明、第三方许可和构建源码。
核心测试：`.\.venv-desktop\Scripts\python.exe -X utf8 -m unittest discover -s tests -v`。
